# Inspiration

Where to look for references beyond the games themselves. Save screenshots and notes in `/research_notes/`, which git ignores.

## Halo interface history

- [Game UI Database](https://www.gameuidatabase.com): searchable menu and HUD screenshots for most Halo games, useful for side-by-side comparisons.
- [Halo 3 HUD Spec](http://www.cand.land/halohud) by David Candland.
- Developer portfolios:
  - [Eric Dies](https://www.mrdies.com/halo-infinite-presentation): Halo Infinite menus, Customization and the design system.
  - [Jeff Christy](https://www.behance.net/gallery/151208619/Halo-Infinite-Reticles): Halo Infinite reticles.
  - [Atomhawk](https://atomhawk.com/project/halo-infinite/): Halo Infinite medals, icons, emblems and nameplates.
- [Inside Infinite, October 2021](https://www.halowaypoint.com/news/inside-infinite-october-2021): the Halo Infinite UI team on their design goals, VISR OS and the HUD.
- [Bungie Weekly Update index](https://www.halopedia.org/Bungie_Weekly_Update): Bungie's development blog from the Halo 3 and Reach era, which sometimes covered UI decisions.
- The "Art of Halo" books, which often include interface and HUD concept art that isn't online.

## Sci-fi interface design

- [HUDS+GUIS](https://www.hudsandguis.com): sci-fi interfaces from film and games, useful for seeing where Halo sits in the wider genre.
- [Sci-fi Interfaces](https://scifiinterfaces.com): critiques sci-fi UIs on usability, not just looks.
- Film interface studios such as [Territory Studio](https://territorystudio.com) and Perception, whose case studies show how sci-fi interfaces are designed.

## Structuring the archive

- Design system documentation, such as the [GOV.UK Design System](https://design-system.service.gov.uk), [Carbon](https://carbondesignsystem.com) and [Material 3](https://m3.material.io). They're good models for each game's Foundations, Components, Reticles and HUD pages, covering anatomy, states and usage.
- Museum and archive collections, such as the [Video Game History Foundation](https://gamehistory.org) and [Cooper Hewitt](https://collection.cooperhewitt.org). They're good models for crediting sources and dating material.

## 3D and shaders

- [Threlte](https://threlte.xyz): Three.js for Svelte, and the place to start for the 3D ring on the home page.
- [The Book of Shaders](https://thebookofshaders.com) and [Shadertoy](https://www.shadertoy.com) for learning shaders.
- [Codrops](https://tympanus.net/codrops/): tutorials on WebGL effects and creative web techniques.
- [Sketchfab](https://sketchfab.com): fan-made Halo ring models to start from. Check each model's licence before using it.
